## 9. 排错

| 现象 | 原因 | 处理 |
|---|---|---|
| `ModuleNotFoundError: No module named 'peft'` | 用了系统 python | 用绝对路径 `/root/autodl-tmp/venv-verl/bin/python` |
| CUDA OOM | seq 太长/没开 checkpoint | `MAX_LEN=1536 GRAD_CKPT=1`，仍 OOM 就 `MAX_LEN=1024` |
| loss 一直是 0.693 | LR 太小 / 数据没进 | LoRA 用 `LR=2e-4`；确认 `train=30000` |
| `train/pair_acc` 一直 0.5 | 同上 | 先跑 300 步看趋势；还平就 `r=32`、`LR=2e-4` |
| eval 分数像随机 | adapter 里没存 `score` | 确认 `modules_to_save=["score"]`；`ls runs/rm-lora/final` 应有 adapter 文件 |
| RewardBench 加载失败 | 网络/数据集名 | 先确认 `HF_ENDPOINT`；仍失败把报错发我，改本地 parquet |
| `chosen==rejected` 很多 | UF 原始数据 | 脚本已过滤；看 clean 前后条数 |
| `Local entry not found` / `Network is unreachable` | 实例外网不通，或 hub 被升到 2.x | `source /etc/network_turbo`；`export HF_HUB_DISABLE_XET=1`；必要时 `pip install "huggingface_hub==0.34.4"` |
| `Unable to find .../uf_rm/train.parquet` | 没跑 `prepare_uf.py`，或它中途失败 | 先 `ls data/uf_rm/` 和 `tail -100 logs/p2_prepare_uf.log`；确认 `train.parquet` 存在再跑 train |
