## 恢复/复现

```bash
# 1) 用 adapter + base 复现评测（不需要 raw checkpoint）
python scripts/p1/merge_lora_peft.py --base Qwen2.5-Math-1.5B-Instruct \
  --adapter merged/r1c/r1c-step600-lora --out merged/r1c/step600-hf
python scripts/eval/eval_math.py --model merged/r1c/step600-hf \
  --data data/eval/math500.jsonl --n 4 --seeds 42,43,44 \
  --prompt-mode legacy --parser v2 --max-new-tokens 3072 --out /tmp/x.json

# 2) 用 raw checkpoint 续训/重新 merge（需要 verl v0.8.0 + 4 个补丁）
python -m verl.model_merger merge --backend fsdp \
  --local_dir checkpoints/rlvr-interview/p1-r1c-rerun-600/global_step_600/actor \
  --target_dir /tmp/step600-raw
```
